A4. Скрипты.
4 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Подключить JavaScript, обработать событие кнопки и вывести результат на странице.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Создай кнопку и область вывода результата.
2. Подключи внешний app.js с defer либо помести script после элементов.
3. Заведи числовой счётчик; меняй его по событию click.
4. Выводи результат через textContent.
5. Добавь сброс и проверь первые десять нажатий; исправь ошибки Console.

ПРОВЕРКА РЕЗУЛЬТАТА
- Один клик увеличивает значение ровно на 1.
- Сброс возвращает 0.
- Нет ошибок из-за ненайденных элементов.

Результат для представления: HTML/JS и пояснение связи события, состояния и DOM.
