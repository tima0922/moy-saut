A14. Функции, использующие язык PHP.
2 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Создать функции для обработки строк и массивов, проверить граничные случаи.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Напиши функцию average с обработкой пустого массива.
2. Напиши функцию нормализации UTF-8 имён с mb_convert_case; проверь наличие mbstring.
3. Используй array_map для обработки массива имён.
4. Отфильтруй значения и объясни сохранение ключей; при необходимости примени array_values.
5. Проверь пустой массив, один элемент, смешанный регистр и кириллицу; выводи результат с HTML-экранированием.

ПРОВЕРКА РЕЗУЛЬТАТА
- Функции возвращают значения и вызываются повторно.
- Нет деления на ноль.
- Кириллица обрабатывается осмысленно, тесты записаны.

Результат для представления: PHP-функции, тестовые входы и полученные результаты.
