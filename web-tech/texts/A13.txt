A13. Работа с синтаксисом языка PHP.
2 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Написать и отладить PHP-программу с ветвлением и циклом.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Создай PHP-обработчик целого балла 0–100 по примеру M13.
2. Проверь наличие, строковый тип и допустимость значения.
3. Сделай ветвление для результата.
4. Обойди массив тестовых баллов циклом foreach.
5. Проверь 0, 60, 100, -1, 101, abc и score[]=60; запиши факт и ожидание.

ПРОВЕРКА РЕЗУЛЬТАТА
- Ноль не путается с false.
- Некорректный ввод имеет понятный ответ.
- Цикл завершается, код проходит локальную php -l.

Результат для представления: PHP-программа и таблица тестов.
