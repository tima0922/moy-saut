ПОРЯДОК ВЫПОЛНЕНИЯ
1. Создай учебную БД и тестовые данные.
2. Настрой PDO по M6.
3. Вынеси подключение из шаблона.
4. Выполни параметризованный SELECT; проверь отсутствующую запись.

ПРИМЕР

<?php
// До запуска создайте БД web_course и таблицу students.
$pdo = new PDO(
    "mysql:host=127.0.0.1;dbname=web_course;charset=utf8mb4",
    "course_user",
    "your_local_password",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
     PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
     PDO::ATTR_EMULATE_PREPARES => false]
);
$stmt = $pdo->prepare("SELECT id, name FROM students WHERE id = :id");
$stmt->execute(["id" => 1]);
$student = $stmt->fetch();
echo $student
    ? htmlspecialchars($student["name"], ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8")
    : "Студент не найден";

ПРОВЕРКА
- Значения передаются отдельно от SQL.
- Ошибки подключения диагностируются в локальном журнале.
- HTML-вывод экранирован.
