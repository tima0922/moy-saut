# A12. Установка веб-сервера на компьютер.

Задание из силабуса: Установить локальный веб-сервер, настроить каталог проекта и проверить журналы.

Методические шаги подготовлены для задания из силабуса.

1. Проверь php -v или установленное PHP-окружение.
2. Создай public/index.php с echo.
3. Запусти php -S 127.0.0.1:8000 -t public либо настроенный Apache.
4. Зафиксируй рабочий URL, корневой каталог и порт.
5. Создай и исправь учебную синтаксическую ошибку, найдя её в журнале; останови сервер после работы.

## Проверка

- PHP исполняется, исходный код не отдаётся как текст.
- Понятно, где смотреть журнал ошибок.
- Другой студент может повторить запуск по инструкции.

Результат: Инструкция запуска и исправленный PHP-файл без общедоступного phpinfo.
