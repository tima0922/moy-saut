# M4. Скрипты.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Выполнение сценариев в браузере. Отличие JavaScript от Java. Переменные, типы данных, условия, циклы и функции. Связь сценария с HTML-документом, события и проверка работы в консоли браузера.

## JavaScript и Java

Это разные языки. В браузере JavaScript связывает действия пользователя с изменением страницы. Скрипт подключают через script; атрибут defer откладывает исполнение внешнего скрипта до разбора HTML.

## Данные и управление

const используют для переменной, которую не переназначают; let — когда переназначение нужно. if выбирает ветку, цикл повторяет действие, функция выделяет переиспользуемую операцию. Проверяй типы значений, полученных из полей: value — строка.

## Событие — обработчик — результат

Найди элемент, подпишись на click через addEventListener и измени textContent. Отдельно храни данные, отдельно обновляй представление. Консоль помогает увидеть ошибку, но результат для пользователя должен появляться на странице.

## Пример

```html
<button id="counter" type="button">Нажатий: 0</button>
<script>
  const button = document.querySelector("#counter");
  let count = 0;
  button.addEventListener("click", () => {
    count += 1;
    button.textContent = `Нажатий: ${count}`;
  });
</script>
```

Каждое нажатие увеличит счётчик на единицу. Перезагрузка сбросит значение.

Обрати внимание: Не обращайся к элементу до его создания. Проверь опечатки в id и первую ошибку в Console.
