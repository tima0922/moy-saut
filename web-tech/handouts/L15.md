# Разбор архивной лабораторной №15: CMS и фреймворки: выбираем осмысленно

Исправленный учебный разбор архивной лабораторной работы.

Для сравнения достаточно документов; установка CMS — необязательное расширение на локальном стенде.

Номер 15 в архиве не означает M15 «Объекты PHP». Для объектов используй M15/A15 и исходную практику №22.

1. Выбери три сценария: блог, магазин, учебный каталог.
2. Для каждого сопоставь CMS, фреймворк и собственное приложение.
3. Объясни управление контентом, структуру кода и зависимости.
4. Определи, кто обновляет ПО и как переносится содержимое.

```text
CMS → готовые функции управления содержимым
Фреймворк → инструменты и правила для разработки
MVC → разделение ответственности в коде
Панель сервера → настройка окружения
Composer → управление PHP-зависимостями
```

## Проверка

- CMS, MVC и панель управления сервером различены.
- У выбора есть обоснование и ограничения.
- Маркетинговые обещания не используются как доказательство.
