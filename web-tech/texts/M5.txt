СОДЕРЖАНИЕ ПО ПРОГРАММЕ
Серверное выполнение PHP-скрипта и включение кода в HTML. Переменные, типы данных, выражения и управляющие конструкции. Работа с объектами и организация кода для обработки запросов.

МЕТОДИЧЕСКИЙ ТЕКСТ ПО ТЕМЕ

ИСПОЛНЕНИЕ ЗАПРОСА
Файл .php должен обрабатываться PHP, а не просто открываться как локальный файл. Код внутри <?php выполняется сервером. echo добавляет данные в ответ. В файле только с PHP закрывающий тег обычно опускают, чтобы избежать случайного вывода.

ТИПЫ И ВЫРАЖЕНИЯ
Имена переменных начинаются с $. Важны различия int, float, string, bool, array, object и null. Точка объединяет строки. В двойных кавычках возможна подстановка переменных. Условия и циклы управляют выполнением кода.

ОТ ДАННЫХ К ОТВЕТУ
Входные значения проверяют до использования. Экранирование зависит от места вывода: для обычного HTML-текста подходит htmlspecialchars с UTF-8. Ошибки выполнения диагностируют по журналу; внутренние детали подключения к БД не нужно показывать посетителю.

ПРИМЕР

<?php
declare(strict_types=1);

$name = "Тимур";
$lessons = 20;
$message = $lessons > 0 ? "Курс доступен" : "Пока пусто";

echo htmlspecialchars($name, ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8");
echo ": " . $message;

Результат: При запуске через PHP будет выведено: Тимур: Курс доступен.

Обратите внимание: Двойной клик по .php не запускает интерпретатор. Сначала настрой окружение по M12.
