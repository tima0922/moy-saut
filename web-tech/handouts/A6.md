# A6. Работа с базами данных в PHP.

Задание из силабуса: Подключить PHP к учебной базе и выполнить параметризованный запрос.

Методические шаги подготовлены для задания из силабуса.

1. Создай отдельную учебную БД web_course. Создай students с id и name; добавь тестовую запись.
2. Настрой локальное соединение PDO, драйвер pdo_mysql и кодировку utf8mb4.
3. Проверь целочисленный id до запроса.
4. Выполни SELECT с плейсхолдером и получи запись.
5. Проверь существующий и отсутствующий id; выведи результат безопасным HTML-текстом.

## Проверка

- Запрос использует prepare и execute.
- Отсутствующая запись обработана отдельно.
- Пароль подключения не включён в публикуемый репозиторий.

Результат: PHP-код, SQL-схема, обезличенные тестовые данные и результаты проверок.
