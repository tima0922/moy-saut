# M20. Интеграция компонентов веб-приложения.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Связь страниц, скриптов и базы данных в законченном приложении. Проверка основных пользовательских сценариев, настройка окружения и подготовка инструкции по запуску учебного проекта.

## Единый пользовательский путь

Выбери небольшой проект: каталог студентов, заметки или список задач. Определи сущности, страницы и операции. Свяжи интерфейс с обработчиками и БД. Не добавляй сложность, пока основной путь не работает от начала до конца.

## Интеграция компонентов

Проверь схему таблиц, параметры PDO, маршруты форм и формат ответов. Учти состояния загрузки, пустого списка и ошибки. После записи покажи результат и проверь его чтением. Для операций изменения нужны серверная валидация, проверка доступа и CSRF-защита при сеансовой авторизации.

## Передача проекта

В README опиши требования, структуру, создание учебной базы, настройки без настоящих секретов, запуск и проверки. Приложи SQL-схему и тестовые данные без персональной информации. На чистом окружении другой человек должен суметь повторить запуск по инструкции.

## Пример

```text
web-project/
  public/
    index.php
    assets/
  src/
    StudentRepository.php
  views/
    students.php
  config/
    database.example.php
  database/
    schema.sql
  README.md

Путь проверки:
список → форма → проверка → запись → повторное чтение
```

Готовый результат — работающий пользовательский сценарий и воспроизводимая инструкция запуска, а не только набор отдельных страниц.

Обрати внимание: Скриншот интерфейса не подтверждает сохранение в БД. Перезагрузи страницу и проверь данные повторным запросом.
