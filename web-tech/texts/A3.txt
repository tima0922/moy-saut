ЗАДАНИЕ ПО ПРОГРАММЕ
Оформить страницу с помощью CSS, проверить блочную модель и адаптацию к ширине окна.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Возьми страницу A2 и подключи отдельный styles.css.
2. Настрой шрифт, контраст, внутренние и внешние отступы через CSS.
3. Собери карточки с Grid или Flexbox.
4. Добавь media query для узкого окна, ограничь ширину изображений.
5. Проверь страницу при ширине 360, 768 и 1280 px, а также фокус с клавиатуры.

ПРОВЕРКА РЕЗУЛЬТАТА
- Основной текст читается без горизонтальной прокрутки.
- Карточки перестраиваются на узком экране.
- Фокус заметен, кнопки не перекрывают текст.

Результат для представления: HTML/CSS и три скриншота адаптивного интерфейса.
