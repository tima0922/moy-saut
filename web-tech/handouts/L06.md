# Разбор архивной лабораторной №6: Построчная обработка файла

Исправленный учебный разбор архивной лабораторной работы.

PHP; logs.txt рядом со скриптом. Исходная работа на Python; ниже — явная адаптация на PHP.

Дополнительная тема. Она не подменяет M6 о базе данных. Память зависит от длины строки; очень длинные строки требуют чтения блоками.

1. Создай logs.txt с обычными строками и ERROR.
2. Открой файл, проверь результат fopen.
3. Читай через fgets в цикле и выведи строки ERROR.
4. Закрой файл в finally; проверь отсутствующий файл.

```php
<?php
// Поместите logs.txt рядом со скриптом. Пример для локального стенда.
$handle = fopen(__DIR__ . "/logs.txt", "r");
if ($handle === false) {
    http_response_code(500);
    exit("Не удалось открыть журнал");
}
try {
    while (($line = fgets($handle)) !== false) {
        if (str_contains($line, "ERROR")) {
            echo htmlspecialchars($line, ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8") . "<br>";
        }
    }
    if (!feof($handle)) throw new RuntimeException("Ошибка чтения");
} finally {
    fclose($handle);
}
```

## Проверка

- Выводятся только нужные строки.
- Отсутствие файла обработано.
- Не используется загрузка всего журнала в массив.
