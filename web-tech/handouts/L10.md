# Разбор архивной лабораторной №10: CRUD в MySQL

Исправленный учебный разбор архивной лабораторной работы.

Отдельная учебная БД; выполнять только в ней. Подойдёт SQL-консоль выбранной СУБД.

Восстановлены запятые в VALUES. Повторный INSERT добавляет новые записи; id=1/2 рассчитаны на первый запуск с пустой таблицей.

1. Выполни CREATE DATABASE и CREATE TABLE.
2. Добавь две тестовые записи с INSERT.
3. Прочитай их SELECT.
4. Измени одну запись UPDATE с WHERE и проверь результат.
5. Удали выбранную запись DELETE с WHERE, затем снова выполни SELECT.

```sql
CREATE DATABASE IF NOT EXISTS web_course CHARACTER SET utf8mb4;
USE web_course;
CREATE TABLE IF NOT EXISTS students (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  age INT NOT NULL
);
INSERT INTO students (name, age) VALUES ('Иван', 20), ('Мария', 22);
SELECT id, name, age FROM students ORDER BY id;
UPDATE students SET age = 21 WHERE id = 1;
SELECT id, name, age FROM students WHERE id = 1;
DELETE FROM students WHERE id = 2;
SELECT id, name, age FROM students ORDER BY id;
```

## Проверка

- Схема создана без синтаксической ошибки.
- Изменение затронуло нужную запись.
- После удаления остальные записи остались.
