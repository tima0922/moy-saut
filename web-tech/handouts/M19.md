# M19. Тестирование и отладка веб-приложения.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Проверка клиентской и серверной логики, инструменты браузера и журналы сервера. Подготовка нормальных, ошибочных и граничных входных значений. Воспроизведение и исправление дефектов.

## Воспроизводимый дефект

Запиши окружение, шаги, входные данные, ожидаемый и фактический результат. Один конкретный пример полезнее формулировки «всё сломалось». Начинай с первой ошибки: последующие могут быть её следствием.

## Инструменты

Console показывает клиентские ошибки, Network — запросы и ответы. Breakpoints помогают пройти исполнение по шагам. Серверный журнал объясняет ошибки PHP и БД. Синтаксис PHP можно предварительно проверить командой php -l, но она не проверит SQL, доступность базы и бизнес-логику.

## Матрица проверок

Для каждого поля нужны нормальное, пустое, некорректное и граничное значения. Для сценария — успех, отказ доступа, отсутствие записи и повторное действие. После исправления повтори исходный пример и связанный сценарий, чтобы не пропустить регрессию.

## Пример

```text
Сценарий: проверка балла 0–100

Вход        Ожидание
60          Зачёт
0           Нужно повторить
100         Зачёт
-1          Ошибка валидации
101         Ошибка валидации
abc         Ошибка валидации
пусто       Ошибка валидации
score[]=60  Ошибка валидации

Проверка синтаксиса: php -l public/index.php
```

У каждой проверки должен быть записан фактический результат. Команда php -l запускается локально при установленном PHP.

Обрати внимание: Успешная проверка синтаксиса не доказывает работоспособность приложения целиком.
