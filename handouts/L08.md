# Разбор архивной лабораторной №8: Файлы, CSV и права

Исправленный учебный разбор архивной лабораторной работы.

PHP и каталог, доступный процессу для чтения/записи.

Дополнение по файловой системе. Маски chmod рассматриваются в контексте владельца, группы, umask и ОС.

1. Определи владельца и права учебного каталога. Не выдавай всем 0777.
2. Запиши строку CSV через fputcsv.
3. Прочитай через fgetcsv, используя тот же разделитель.
4. Проверь повторный запуск и отсутствие прав на запись.

```php
<?php
$path = __DIR__ . "/students.csv";
$handle = fopen($path, "a");
if ($handle === false) exit("Не удалось открыть файл для записи");
try {
    if (fputcsv($handle, ["Тимур", "student"], ";", '"', "") === false) {
        throw new RuntimeException("Ошибка записи");
    }
} finally {
    fclose($handle);
}
$handle = fopen($path, "r");
if ($handle === false) exit("Не удалось открыть файл для чтения");
try {
    while (($row = fgetcsv($handle, 0, ";", '"', "")) !== false) {
        echo htmlspecialchars(implode(" — ", $row), ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8") . "<br>";
    }
} finally {
    fclose($handle);
}
```

## Проверка

- Данные читаются в том же формате.
- Ресурс закрывается.
- Ошибка открытия обработана.
