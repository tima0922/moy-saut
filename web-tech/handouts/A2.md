# A2. Язык разметки гипертекста.

Задание из силабуса: Создать семантическую HTML-страницу с текстом, таблицей, изображениями и формой.

Методические шаги подготовлены для задания из силабуса.

1. Создай index.html с DOCTYPE, lang, charset, viewport и title.
2. Размести header, nav, main и footer; выстрой заголовки по смыслу.
3. Добавь текст, ссылку, изображение с alt и список.
4. Создай таблицу с caption, th и несколькими строками.
5. Добавь форму с label, полем name и кнопкой. Проверь вкладку Elements и навигацию Tab.

## Проверка

- Все ссылки ведут к существующим целям.
- У полей есть видимые подписи; у изображения — подходящий alt.
- Таблица содержит заголовки, id не повторяются.

Результат: HTML и локальные изображения; список выполненных проверок.
