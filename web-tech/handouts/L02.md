# Разбор архивной лабораторной №2: События с jQuery

Исправленный учебный разбор архивной лабораторной работы.

HTML-страница и локальная библиотека jquery.js из официального дистрибутива.

Скрипт требует настоящую библиотеку jQuery. В сайте не используется имитация её API.

1. Создай кнопку #toggle и блок #panel.
2. Подключи jQuery перед собственным кодом.
3. Реализуй .on("click") и переключение hidden.
4. Сравни с обычным JavaScript на отдельной странице.

```html
<button id="toggle" type="button">Показать / скрыть</button>
<p id="panel">Учебный блок</p>
<script src="jquery.js"></script>
<script>
$(function () {
  $("#toggle").on("click", function () {
    const panel = $("#panel");
    panel.prop("hidden", !panel.prop("hidden"));
  });
});
</script>
```

## Проверка

- Нет ошибки $ is not defined.
- Кнопка работает с мыши и клавиатуры.
- Повторное нажатие возвращает блок.
