# M13. Работа с синтаксисом языка PHP.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Синтаксис выражений, условных операторов и циклов PHP. Организация линейных и разветвляющихся алгоритмов. Проверка входных значений и обработка типовых ошибок выполнения.

## Алгоритм обработки

Сначала получи вход, затем проверь структуру и допустимость значения, затем вычисли результат. Значения HTTP-параметров обычно строки или массивы. Нельзя без проверки передавать произвольный параметр в арифметику или функцию, ожидающую строку.

## Ветвление и повторение

if/elseif/else выбирает ветвь, for повторяет действие с известным счётчиком, foreach обходит массив. Условие цикла должно меняться так, чтобы выполнение завершалось. Неопределённую переменную нужно устранить в логике, а не скрывать ошибку.

## Граничные значения

Для числа от 0 до 100 проверь 0, 100, -1, 101, пустую строку и нечисловой ввод. filter_var может вернуть false; сравнение должно быть строгим, потому что корректный ноль тоже ложный в булевом контексте.

## Пример

```php
<?php
$raw = $_GET["score"] ?? "";
$score = is_string($raw)
    ? filter_var($raw, FILTER_VALIDATE_INT)
    : false;

if ($score === false || $score < 0 || $score > 100) {
    http_response_code(422);
    echo "Нужно целое число от 0 до 100";
} else {
    echo $score >= 60 ? "Зачёт" : "Нужно повторить";
}

foreach ([0, 60, 100] as $value) {
    echo "
Проверено: " . $value;
}
```

Открой файл через PHP-сервер с ?score=60: появится «Зачёт» и три проверочных значения.

Обрати внимание: if (!$score) ошибочно отвергнет 0. Сравнивай результат валидации с false через ===.
