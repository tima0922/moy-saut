МЕТОДИЧЕСКИЙ ТЕКСТ ПО ТЕМЕ

КОНТРАКТ ФУНКЦИИ
Функция принимает параметры и возвращает результат через return. Аргумент — конкретное значение при вызове. Локальные переменные недоступны снаружи. Типы параметров и результата помогают выявлять несогласованность кода, но не заменяют проверку предметных ограничений.

КОЛЛЕКЦИИ И ТЕКСТ
array_map преобразует элементы, array_filter отбирает их и сохраняет ключи. При необходимости последовательных индексов используй array_values. explode разбивает строку, implode собирает. strlen считает байты; для длины UTF-8 текста по символам используют mb_strlen при наличии расширения mbstring.

ПОВТОРНОЕ ИСПОЛЬЗОВАНИЕ
Делай функцию с одной понятной задачей. Возвращаемое значение удобно тестировать отдельно от вывода HTML. Рекурсия требует условия завершения и корректных данных: дерево с циклом может не закончить обход. Не смешивай обработку текста с его экранированием для произвольного контекста.

ПРИМЕР

<?php
declare(strict_types=1);

function add(int $a, int $b): int {
    return $a + $b;
}

function average(array $numbers): float {
    if ($numbers === []) {
        return 0.0;
    }
    return array_sum($numbers) / count($numbers);
}

$numbers = [1, 2, 3];
$doubled = array_map(fn(int $n): int => $n * 2, $numbers);
echo average($numbers); // 2
echo "
" . implode(", ", $doubled); // 2, 4, 6
echo "
" . average([]); // 0

Результат: Будут выведены 2, затем 2, 4, 6, затем 0. Пустой массив не вызывает деление на ноль.

Обратите внимание: Для преобразования кириллических имён используй mb_convert_case с UTF-8, а не ucfirst.

ВОПРОСЫ ДЛЯ САМОПРОВЕРКИ
Чем return отличается от echo?
return возвращает значение вызывающему коду; echo выводит текст в ответ.

Почему отдельно обрабатываем []?
Чтобы не делить сумму на нулевое количество элементов.
