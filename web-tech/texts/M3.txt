СОДЕРЖАНИЕ ПО ПРОГРАММЕ
Назначение CSS, способы подключения таблиц стилей и выбор элементов. Каскад, наследование и специфичность. Блочная модель, размеры, отступы и расположение элементов. Основы адаптивного оформления.

МЕТОДИЧЕСКИЙ ТЕКСТ ПО ТЕМЕ

СЕЛЕКТОРЫ И КАСКАД
Правило CSS связывает селектор со свойствами. Каскад учитывает происхождение, важность, слои, специфичность и порядок правил. При прочих равных более специфичный селектор выигрывает; у равных — более поздний. Наследуются лишь некоторые свойства, например color.

БЛОЧНАЯ МОДЕЛЬ
Размер элемента складывается из содержимого, padding и border; margin находится снаружи. box-sizing: border-box включает padding и border в заданную ширину. Flexbox удобен для одномерного расположения, Grid — для строк и колонок.

АДАПТИВНОСТЬ
Не привязывай страницу к одному экрану. Используй max-width, относительные размеры и media queries. Проверяй текст, поля и изображения на узком экране. Контраст и видимый фокус — часть оформления, а не необязательное украшение.

ПРИМЕР

* { box-sizing: border-box; }
body { margin: 0; font: 18px/1.6 system-ui; }
main { width: min(100% - 32px, 960px); margin: 40px auto; }
.cards { display: grid; grid-template-columns: repeat(2, 1fr); gap: 24px; }
.card { padding: 24px; border: 1px solid #687078; border-radius: 16px; }
button:focus-visible { outline: 3px solid #1765b8; outline-offset: 4px; }
@media (max-width: 600px) {
  .cards { grid-template-columns: 1fr; }
}

Результат: Для контейнера .cards: две колонки на широком экране и одна при ширине окна не более 600 px.

Обратите внимание: Если блок вылезает за экран, проверь фиксированную ширину, минимальные размеры Grid и длинные неразрывные строки.

ВОПРОСЫ ДЛЯ САМОПРОВЕРКИ
Чем padding отличается от margin?
padding находится внутри рамки, margin — снаружи.

Зачем border-box?
Чтобы заданная ширина включала рамку и внутренние отступы.
