A15. Работа с объектами в PHP.
2 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Создать PHP-класс, экземпляры и методы для обработки данных учебного приложения.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Создай класс Rectangle по M15.
2. Сделай размеры private и задай их в __construct.
3. Добавь метод area и создай два разных объекта.
4. Проверь положительные размеры и ошибочные 0/-1.
5. Обработай ожидаемое исключение в тестовом сценарии и объясни роль $this.

ПРОВЕРКА РЕЗУЛЬТАТА
- Объекты хранят независимое состояние.
- Снаружи нельзя менять private-поле напрямую.
- Входные ограничения проверяются конструктором.

Результат для представления: PHP-класс, сценарий создания объектов и таблица проверок.
