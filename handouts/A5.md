# A5. Язык и синтаксис PHP.

Задание из силабуса: Создать PHP-скрипт с переменными, условиями и обработкой входных значений.

Методические шаги подготовлены для задания из силабуса.

1. Проверь PHP-окружение по M12; создай public/index.php.
2. Создай переменные разных типов и простое условие.
3. Прими строковый параметр name из запроса; отдельно проверь его тип и пустое значение.
4. Выведи проверенное имя через htmlspecialchars в HTML.
5. Проверь обычное имя, пустую строку, name[]=a и строку с угловыми скобками.

## Проверка

- Страница выполняется PHP-сервером.
- Некорректная структура параметра не вызывает необработанную ошибку.
- Введённая разметка видна как текст.

Результат: PHP-файл, адрес запуска и таблица входных значений.
