# wong.uz — личное пространство Тимура

- [/](https://wong.uz/) — панель выбора проектов: анимированная планета, превью, Telegram [@tima_bt](https://t.me/tima_bt).
- [/web-tech/](https://wong.uz/web-tech/) — Web Studio / учебные материалы «Веб технологии I» TIFT.
- [/2/](https://wong.uz/2/) — PACKET Academy.
- [/netlab/](https://wong.uz/netlab/) — NetLab 3D.

Главная: `index.html`, стили и логика: `portal/`. Без сборщика и внешних зависимостей; локальные шрифты из `2/fonts/`. Публикация через существующий GitHub Pages, домен в `CNAME`.

Эффекты учитывают `prefers-reduced-motion`; кнопка внизу сохраняет настройку паузы. Canvas останавливается в фоновой вкладке, частота отрисовки ограничена 30 fps. Навигация работает без JavaScript. Старые ссылки на разделы курса в корне (`/#course` и т. п.) перенаправляются на `/web-tech/` с сохранением раздела. Прогресс курса в localStorage сохраняется при переносе в пределах домена.
