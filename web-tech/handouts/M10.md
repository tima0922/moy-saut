# M10. Работа с JavaScript в операционных системах.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Возможности JavaScript в браузерной среде и взаимодействие с пользовательским интерфейсом. Объектная модель документа, события и управление состоянием страницы. Ограничения доступа сценария к ресурсам операционной системы.

## Страница как дерево

DOM представляет элементы документа объектами. querySelector выбирает первый подходящий элемент. createElement создаёт новый, append добавляет его, remove удаляет. DOM — интерфейс среды браузера, а не часть самого синтаксиса JavaScript.

## Управление состоянием

События input, submit, click и keydown позволяют реагировать на пользователя. preventDefault отменяет стандартное действие события, если оно отменяемое. Для интерфейса полезно отделять состояние от функции отображения и обрабатывать пустые значения.

## Операционная система

Обычная страница не может произвольно читать файлы или запускать процессы ОС. Доступ к некоторым возможностям идёт через специальные браузерные API и разрешения. Node.js — другая среда с другими полномочиями. Хранение localStorage относится к происхождению сайта и может быть недоступно по настройкам браузера.

## Пример

```html
<label for="name">Имя</label>
<input id="name" autocomplete="given-name">
<p id="greeting" aria-live="polite">Введи имя</p>
<script>
  const input = document.querySelector("#name");
  const output = document.querySelector("#greeting");
  input.addEventListener("input", () => {
    const name = input.value.trim();
    output.textContent = name ? `Привет, ${name}!` : "Введи имя";
  });
</script>
```

Приветствие обновляется при вводе; пробелы по краям убираются. HTML в имени выводится обычным текстом.

Обрати внимание: Не переноси node:fs в браузерный script: это API другой среды.
