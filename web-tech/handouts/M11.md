# M11. Создание библиотек JavaScript.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Назначение библиотек JavaScript, подключение и повторное использование кода. Базовые возможности jQuery, выбор элементов и обработка событий. Проверка зависимостей и сопоставление библиотечных решений с обычным JavaScript.

## Повторное использование

Библиотека выделяет общие операции в интерфейс, который можно использовать повторно. Важно документировать входные параметры, результаты и зависимости. Для небольшой задачи полезно сначала понять реализацию обычным JavaScript.

## jQuery и DOM

jQuery предоставляет выбор элементов, обработку событий и изменение страницы. Библиотека должна загрузиться до использующего её кода. jQuery UI добавляет виджеты и зависит от jQuery. Если $ не определён, проверь порядок подключения и успешность загрузки.

## Сравнение решений

В примере показано одно поведение двумя способами. Не подключай оба обработчика к одной кнопке одновременно: действие будет выполнено дважды. Создание npm-пакета из архивной лекции — дополнительный уровень; для A11 достаточно подключения и осмысленного сравнения.

## Пример

```javascript
// Вариант 1: обычный JavaScript
document.querySelector("#toggle").addEventListener("click", () => {
  document.querySelector("#panel").hidden =
    !document.querySelector("#panel").hidden;
});

// Вариант 2: jQuery уже подключён, используйте вместо варианта 1
$("#toggle").on("click", function () {
  const panel = $("#panel");
  panel.prop("hidden", !panel.prop("hidden"));
});
```

При наличии кнопки #toggle и блока #panel выбранный вариант переключит видимость блока.

Обрати внимание: Код библиотеки не делает недоверенный HTML безопасным. jQuery .html() и .text() решают разные задачи.
