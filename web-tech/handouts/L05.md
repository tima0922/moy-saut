# Разбор архивной лабораторной №5: Рекурсия: дерево категорий

Исправленный учебный разбор архивной лабораторной работы.

PHP; учебный массив должен описывать дерево.

Защита глубины не заменяет валидацию структуры. Для больших деревьев нужен индекс детей по parent_id.

1. Определи id и parent_id для категорий.
2. Сделай рекурсивную функцию с параметром parentId.
3. Экранируй названия при HTML-выводе.
4. Добавь ограничение глубины и проверь пустую ветку.

```php
<?php
$items = [
  ["id" => 1, "parent_id" => 0, "name" => "Техника"],
  ["id" => 2, "parent_id" => 1, "name" => "Ноутбуки"]
];
function tree(array $items, int $parent = 0, int $depth = 0): void {
    if ($depth > 20) throw new RuntimeException("Проверьте структуру дерева");
    $children = array_filter($items, fn(array $item): bool => $item["parent_id"] === $parent);
    if ($children === []) return;
    echo "<ul>";
    foreach ($children as $item) {
        echo "<li>" . htmlspecialchars($item["name"], ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8");
        tree($items, $item["id"], $depth + 1);
        echo "</li>";
    }
    echo "</ul>";
}
tree($items);
```

## Проверка

- Получается вложенный список.
- Названия не превращаются в HTML.
- Пустые ветки завершают обход.
