СОДЕРЖАНИЕ ПО ПРОГРАММЕ
Выражения, операторы и преобразование типов в JavaScript. Объекты, свойства и методы. Логические условия и управление выполнением сценария. Проверка результатов операций на примерах.

МЕТОДИЧЕСКИЙ ТЕКСТ ПО ТЕМЕ

ВЫРАЖЕНИЕ И РЕЗУЛЬТАТ
Выражение вычисляет значение: 2 + 3, user.name или вызов функции. Операторы сравнения возвращают boolean; === сравнивает без приведения типов. Логические && и || возвращают один из операндов, а не обязательно true или false.

ПРЕОБРАЗОВАНИЕ ТИПОВ
Строка "5" и число 5 — разные значения. Оператор + со строкой может выполнить конкатенацию. Number преобразует строку в число; результат стоит проверить Number.isFinite. Пустая строка при Number превращается в 0, поэтому обязательность поля проверяют отдельно.

ОБЪЕКТ И СВОЙСТВА
Объект объединяет свойства и методы. Через точку обращаются по известному имени, через квадратные скобки — в том числе по имени из переменной. const не замораживает свойства объекта. Скобки помогают явно задать порядок вычислений.

ПРИМЕР

const student = { name: "Тимур", score: 70 };
student.score += 10;
const passed = student.score >= 60;
const label = `${student.name}: ${passed ? "зачёт" : "повторить"}`;
console.log(label);
console.log("5" + 2, Number("5") + 2);
console.log(5 === "5");

Результат: Тимур: зачёт; затем 52 и 7; затем false.

Обратите внимание: Не используй = вместо сравнения. Проверяй типы до вычисления, особенно после чтения value из формы.

ВОПРОСЫ ДЛЯ САМОПРОВЕРКИ
Почему "5" + 2 даёт "52"?
Один операнд — строка, поэтому выполняется конкатенация.

Можно менять поле объекта const?
Да: запрещено переназначение самой переменной, а не изменение её объекта.
