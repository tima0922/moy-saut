A1. Базовые концепции разработки веб-приложений.
4 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Построить схему обработки HTTP-запроса и запустить первую страницу на локальном сервере.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Создай каталог проекта с public/index.html и заголовком h1.
2. Запусти локальный сервер по инструкции M12. Открой страницу через http://localhost или 127.0.0.1.
3. Открой DevTools → Network и обнови страницу. Зафиксируй URL, метод, статус и Content-Type.
4. Запроси несуществующий путь; сравни статус и тело ответа.
5. Построй схему браузер → сервер → ответ и объясни, где мог бы выполняться PHP.

ПРОВЕРКА РЕЗУЛЬТАТА
- Страница доступна по HTTP.
- Для существующей страницы записан успешный ответ, для отсутствующей — фактический ответ сервера.
- Схема различает HTTP-запрос и ответ.

Результат для представления: HTML-файл, схема обмена и краткое наблюдение по Network.
