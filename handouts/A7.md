# A7. Базовая структура контента и управления, работающая на PHP.

Задание из силабуса: Разделить небольшой PHP-проект на представление, обработчик и слой доступа к данным.

Методические шаги подготовлены для задания из силабуса.

1. Выбери маленький каталог студентов.
2. Вынеси получение данных в model.php или отдельный репозиторий.
3. Создай контроллер index.php, который получает данные и подключает представление.
4. Вынеси HTML в view.php, сохрани экранирование данных.
5. Замени источник данных в модели и убедись, что разметку менять не пришлось.

## Проверка

- В представлении нет SQL и настройки подключения.
- Контроллер выбирает сценарий, модель получает данные.
- Страница запускается через одну понятную точку входа.

Результат: Разделённый проект из нескольких файлов и схема их ответственности.
