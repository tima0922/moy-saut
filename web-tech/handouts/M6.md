# M6. Работа с базами данных в PHP.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Реляционная модель данных и назначение SQL. Подключение к базе из PHP, выполнение запросов и обработка результатов. Параметризованные запросы, проверка ошибок и безопасная работа с пользовательскими данными.

## Реляционная модель

Таблица содержит строки и столбцы. Первичный ключ однозначно определяет запись, внешний связывает таблицы. SQL позволяет выбирать и изменять данные. CREATE TABLE относится к описанию структуры, INSERT, UPDATE и DELETE — к изменению данных.

## Соединение через PDO

Для MySQL нужен драйвер pdo_mysql, работающий сервер и учебная БД. DSN задаёт хост, базу и charset=utf8mb4. Используй отдельного пользователя с нужными правами. Режим исключений делает ошибки заметными во время отладки.

## Данные отдельно от SQL

Передавай значения через prepare/execute. Плейсхолдер обозначает значение, а не имя таблицы, столбца или ключевое слово. Динамические имена выбирают из разрешённого списка. Полученные из БД значения тоже требуют экранирования при выводе в HTML.

## Пример

```php
<?php
// До запуска создайте БД web_course и таблицу students.
$pdo = new PDO(
    "mysql:host=127.0.0.1;dbname=web_course;charset=utf8mb4",
    "course_user",
    "your_local_password",
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
     PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
     PDO::ATTR_EMULATE_PREPARES => false]
);
$stmt = $pdo->prepare("SELECT id, name FROM students WHERE id = :id");
$stmt->execute(["id" => 1]);
$student = $stmt->fetch();
echo $student
    ? htmlspecialchars($student["name"], ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8")
    : "Студент не найден";
```

Имя записи с id=1 либо «Студент не найден». Параметры подключения нужно настроить на своём компьютере.

Обрати внимание: prepare не отменяет проверку прав доступа и входных данных. Никогда не собирай SQL из пользовательской строки.
