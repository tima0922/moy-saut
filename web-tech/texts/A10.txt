A10. Работа с JavaScript в операционных системах.
2 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Реализовать работу с DOM и событиями, проверить сценарий в инструментах браузера.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Создай форму добавления заметки с label, input и списком.
2. Обработай submit через addEventListener и preventDefault.
3. Проверь trim-значение; пустую заметку не добавляй.
4. Добавляй текст через textContent, реализуй удаление.
5. Проверь клавиатуру, Console и поведение после перезагрузки; объясни границы доступа браузера к ОС.

ПРОВЕРКА РЕЗУЛЬТАТА
- Enter и кнопка работают одинаково.
- Текст с <b> не превращается в HTML.
- Удаляется выбранная запись.

Результат для представления: HTML/JS, список событий и описание состояния.
