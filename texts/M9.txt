СОДЕРЖАНИЕ ПО ПРОГРАММЕ
Создание, изменение и обход массивов в JavaScript. Основные операции над последовательностями данных. Применение условий, циклов и функций при обработке массива. Связь обработки данных с изменением элементов страницы.

МЕТОДИЧЕСКИЙ ТЕКСТ ПО ТЕМЕ

КОЛЛЕКЦИЯ С ИНДЕКСАМИ
Первый индекс массива — 0. length показывает длину. push добавляет элемент в конец и возвращает новую длину; pop удаляет и возвращает последний элемент. slice делает поверхностную копию участка, splice меняет исходный массив.

ПРЕОБРАЗОВАНИЕ И ОТБОР
map формирует массив результатов, filter оставляет подходящие элементы, find возвращает первый подходящий элемент или undefined. reduce сводит значения к одному результату. forEach используют для действий при обходе; его результат — undefined.

ОТРИСОВКА СПИСКА
Держи массив как источник данных, а DOM — как представление. При изменении данных заново обнови список или нужный элемент. Для пользовательского текста создавай элементы и присваивай textContent. При сортировке чисел нужен компаратор (a, b) => a - b.

ПРИМЕР

const scores = [40, 80, 65, 90];
const passed = scores.filter(score => score >= 60);
const doubled = scores.map(score => score * 2);
const total = scores.reduce((sum, score) => sum + score, 0);
console.log(passed);
console.log(doubled);
console.log(total);
console.log([...scores].sort((a, b) => a - b));

Результат: [80, 65, 90]; [80, 160, 130, 180]; 275; [40, 65, 80, 90]. Исходный scores не отсортирован.

Обратите внимание: sort меняет исходный массив. Копия через spread поверхностная: вложенные объекты остаются общими.

ВОПРОСЫ ДЛЯ САМОПРОВЕРКИ
Что вернёт push?
Новую длину массива.

Чем filter отличается от map?
filter отбирает элементы, map преобразует каждый элемент.
