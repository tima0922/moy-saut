# M2. Язык разметки гипертекста.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Структура HTML-документа, элементы и атрибуты. Семантическая разметка текста, списков, ссылок, изображений и таблиц. Формы и элементы пользовательского ввода. Проверка корректности структуры страницы.

## Каркас документа

DOCTYPE включает стандартный режим отображения. В html указывают язык, в head — кодировку, заголовок вкладки и метаданные. В body располагается содержимое страницы. main, header, nav и footer объясняют назначение частей документа.

## Текст, изображения и таблицы

Заголовки отражают структуру, p содержит абзац, ul/ol — списки, a с href — ссылку. Изображению нужен осмысленный alt; декоративному — пустой alt. Таблица описывает табличные данные: caption даёт название, th — заголовки, td — значения.

## Формы и доступность

У каждого поля должен быть label. name задаёт ключ отправляемого значения, type определяет назначение поля. required помогает пользователю, но не заменяет серверную проверку. Отступы и цвета задаются CSS, а не устаревшими font и bgcolor.

## Пример

```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Карточка студента</title>
</head>
<body>
  <main>
    <h1>Карточка студента</h1>
    <p>Изучаю веб-технологии.</p>
    <form method="get">
      <label for="student">Имя</label>
      <input id="student" name="student" required>
      <button type="submit">Отправить</button>
    </form>
  </main>
</body>
</html>
```

Браузер покажет заголовок, абзац и форму; после отправки значение student появится в строке запроса.

Обрати внимание: Не используй placeholder вместо label. Проверь вложенность элементов, уникальность id и навигацию клавишей Tab.
