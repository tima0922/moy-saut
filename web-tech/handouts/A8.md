# A8. Выражения и операции в JavaScript.

Задание из силабуса: Реализовать вычисления и изменение свойств объекта в JavaScript.

Методические шаги подготовлены для задания из силабуса.

1. Создай объект товара с названием, ценой и количеством.
2. Вычисли итоговую стоимость; измени количество и пересчитай.
3. Получи число из поля формы через Number после проверки пустого ввода.
4. Проверь Number.isFinite и неотрицательность.
5. Выведи свойства и результат в DOM, сравни "5" + 2 с Number("5") + 2.

## Проверка

- Меняются и данные объекта, и результат на странице.
- Пустой ввод не превращается незаметно в корректную покупку.
- Строковые и числовые операции различены в пояснении.

Результат: HTML/JS, тестовые значения и объяснение преобразования типов.
