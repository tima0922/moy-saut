A11. Создание библиотек JavaScript.
2 ч по учебной программе

ЗАДАНИЕ ПО ПРОГРАММЕ
Подключить jQuery и сопоставить обработчик события с обычным JavaScript.

МЕТОДИЧЕСКИЙ ПОРЯДОК ВЫПОЛНЕНИЯ
1. Подготовь кнопку #toggle и блок #panel.
2. Подключи локальную копию jQuery из официального дистрибутива до своего скрипта.
3. Реализуй переключение hidden через .on и .prop.
4. На отдельной странице реализуй то же через addEventListener.
5. Сравни код, порядок загрузки и поведение. Виджеты jQuery UI исследуй как расширение.

ПРОВЕРКА РЕЗУЛЬТАТА
- jQuery действительно загружен без ошибок.
- Оба варианта дают одинаковый результат.
- Одновременно не выполняются два обработчика одного действия.

Результат для представления: Два варианта страницы и краткое сравнение зависимости/объёма кода.
