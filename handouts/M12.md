# M12. Установка веб-сервера на компьютер.

Учебный разбор, подготовленный по теме силабуса.

По силабусу: Назначение локального веб-сервера и его компонентов. Установка окружения, корневой каталог сайта, запуск и остановка сервисов. Проверка обработки PHP и чтение журналов при диагностике ошибок.

## Нужные компоненты

Для PHP-проекта нужны интерпретатор PHP и сервер, который передаст ему запрос. Для задач с БД дополнительно нужна СУБД и драйвер. XAMPP объединяет Apache, MariaDB, PHP и вспомогательные инструменты. Статический сервер обслуживает HTML/CSS/JS, но не исполняет PHP.

## Путь и порт

localhost указывает на локальную машину. Порт отличает службы. Корневой каталог определяет, какие файлы доступны по URL. Во встроенном сервере PHP каталог задают флагом -t; ниже public — каталог проекта, а не произвольный системный путь.

## Проверка запуска

Сначала убедись, что команда php доступна. Создай public/index.php и открой адрес из терминала в браузере. Если порт занят, выбери другой. Не закрывай терминал до конца работы. Ошибки ищи в выводе сервера и Network; обычное изменение PHP-файла не требует перезапуска встроенного сервера.

## Пример

```bash
php -v
# Выполняйте из каталога своего проекта.
# Создайте папку public и файл public/index.php:
# <?php echo "Сервер работает";
php -S 127.0.0.1:8000 -t public
# Откройте http://127.0.0.1:8000
# Ctrl+C останавливает сервер.
```

В браузере появится «Сервер работает». Если php не найден, установи PHP или используй настроенное окружение XAMPP.

Обрати внимание: Встроенный сервер PHP предназначен для разработки. phpinfo раскрывает настройки — не оставляй его общедоступным.
