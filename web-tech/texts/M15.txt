МЕТОДИЧЕСКИЙ ТЕКСТ ПО ТЕМЕ

КЛАСС И ЭКЗЕМПЛЯР
Класс описывает свойства и методы; объект — конкретный экземпляр, созданный через new. Каждый экземпляр имеет своё состояние. $this указывает на текущий объект в нестатическом методе.

КОНСТРУКТОР И ДОСТУП
__construct инициализирует объект. public доступен снаружи, private — внутри класса, protected — также в наследниках. Закрытые свойства помогают сохранить инварианты: например, не допустить отрицательную ширину.

ОБЪЕКТ В ПРИЛОЖЕНИИ
Классы удобно использовать для сущностей, сервисов и доступа к данным. Наследование — только один инструмент; для начала достаточно одного небольшого класса с проверкой входных значений и методом. Не превращай каждую переменную в отдельный класс.

ПРИМЕР

<?php
declare(strict_types=1);

class Rectangle {
    private float $width;
    private float $height;

    public function __construct(float $width, float $height) {
        if ($width <= 0 || $height <= 0) {
            throw new InvalidArgumentException("Размеры должны быть положительными");
        }
        $this->width = $width;
        $this->height = $height;
    }

    public function area(): float {
        return $this->width * $this->height;
    }
}

$rectangle = new Rectangle(10, 5);
echo $rectangle->area(); // 50

Результат: Вывод: 50. При неположительном размере конструктор выбросит исключение.

Обратите внимание: Пиши __construct без пробела; в архивной узбекской лекции это имя повреждено.

ВОПРОСЫ ДЛЯ САМОПРОВЕРКИ
Что такое $this?
Ссылка на текущий экземпляр класса.

Почему width private?
Чтобы внешний код не менял размер в обход проверки класса.
