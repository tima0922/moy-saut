# Разбор архивной лабораторной №4: Массивы и строки PHP

Исправленный учебный разбор архивной лабораторной работы.

PHP с mbstring; сохраните код как names.php.

Исправлена обработка кириллицы; посторонние фрагменты исключены из учебного разбора.

1. Создай массив имён в разном регистре.
2. Используй mb_convert_case с UTF-8.
3. Преобразуй массив через array_map.
4. Удали дубли из массива ID через array_unique и сравни ключи.

```php
<?php
$names = ["дмитрий", "АЛЕКСЕЙ", "иван"];
$formatted = array_map(
    fn(string $name): string => mb_convert_case(trim($name), MB_CASE_TITLE, "UTF-8"),
    $names
);
foreach ($formatted as $name) {
    echo htmlspecialchars($name, ENT_QUOTES | ENT_SUBSTITUTE, "UTF-8") . "<br>";
}
$ids = array_values(array_unique([10, 5, 20, 5, 30, 10, 50]));
$ids[] = 100;
echo implode("|", $ids);
```

## Проверка

- Кириллица преобразована.
- Вывод экранирован для HTML.
- Пустой массив не вызывает ошибку.
