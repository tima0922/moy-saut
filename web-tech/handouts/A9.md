# A9. Работа с массивами в JavaScript.

Задание из силабуса: Обработать массив в JavaScript и вывести результат в HTML-документ.

Методические шаги подготовлены для задания из силабуса.

1. Создай массив объектов студентов с именем и баллом.
2. Отбери записи по условию через filter.
3. Сформируй новый набор значений через map.
4. Выведи список через createElement и textContent.
5. Добавь запись, перерисуй список и проверь пустой массив.

## Проверка

- Обрабатывается именно массив, а не заранее написанный HTML.
- Отбор соответствует условию.
- Пустой список имеет понятное сообщение.

Результат: HTML/JS и пример массива до и после обработки.
