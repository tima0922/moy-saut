# Два сайта на одном домене

- [NetLab 3D](https://wong.uz/) — существующий сайт в корне репозитория.
- [Учебный план TIFT](https://wong.uz/web-tech/) — новый сайт в папке web-tech/.

Корневые файлы NetLab и CNAME сохранены без изменений. В web-tech/ находятся HTML, CSS, JavaScript и учебные материалы нового сайта. Все пути относительные, поэтому оба сайта работают независимо на одном домене.

Дополнительные генераторы и исходные служебные JSON не включены. Для запуска опубликованного сайта они не нужны.
